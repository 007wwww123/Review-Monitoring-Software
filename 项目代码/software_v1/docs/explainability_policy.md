# 解释边界政策

## 可以展示

- 融合真假概率、使用阈值和最终审核建议；
- ALBERT真假辅助概率及四维语义相对匹配度；
- GRU正常/异常辅助概率、五维行为相对匹配度和历史可用状态；
- 门控向量均值形成的语义/行为权重摘要。

## 禁止表述

- 不得把门控权重称为因果贡献或“模型判假的真实原因”；
- 不得把未经独立标签监督和校准的匹配度称为确定类别概率；
- 不得把评论真假代理标签称为独立人工标注的行为异常真值；
- 历史不足时不得输出可靠的正常行为或具体异常类型；
- 检测结果不得替代人工事实认定。

在线接口只生成轻量证据摘要。SHAP、Integrated Gradients和TimeSHAP属于按需或离线治理工具，未接入主推理请求，不在V1.0界面中承诺实时生成。
